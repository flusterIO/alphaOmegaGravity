# $\alpha \omega$ Gravity

## Usage

You'll probably want to import things from these tunnel files:

```py
import physics.symbolic as s
import physics.notebook as nb
import physics.functions as p
```

And to be honest, you're just going to have to explore. Some of the functions are just standard physics functions, others have to do with the paper [here](https://zenodo.org/records/24280888), and some are part of the work that I'm currently focused on, not yet published anywhere.
